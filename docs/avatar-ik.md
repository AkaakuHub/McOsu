# アバターのIK

腕と脚の2ボーンIKはozz-animation 0.16.0の`IKTwoBoneJob`を使用します。依存先はGitサブモジュールで固定しています。MITライセンスは`third_party/ozz-animation/LICENSE.md`にあります。

腰、左右の足、左右の肘はSteamVRの識別番号で割り当てます。実測の肘は腕の曲がる平面を決め、ozzのソルバーはモデルの骨長を維持します。肩の回転は可動範囲内で補います。手首の推定ねじれ補正は実測腕に適用しません。膝の曲げ方向は腰の向きから計算します。膝そのものは計測していないため、足と腰からIKで求めます。

これは全身ソルバー全体をozzへ置き換えた実装ではありません。体幹の計算、トラッカーとモデルの位置合わせ、衣服の衝突は別の処理です。姿勢テストと実機での見た目の確認は両方必要です。

頂点変形は1フレームにつき1回だけ行い、左右の目とPCカメラで共有します。`VRM frame`ログにはフレーム時間と、姿勢計算、揺れ骨、頂点変形の処理時間をミリ秒で記録します。

身体のルートはモデル原点ではなく目の位置をHMDへ合わせます。途中で腰・足のトラッカーを追加した場合は、現在の関節位置を基準に装着オフセットを求め、初期姿勢へ飛ばないようにします。追跡モードや座標原点が変わった場合は、衣服へ架空の慣性が加わらないよう揺れ骨の履歴をリセットします。

揺れ骨のカプセル判定はUniVRM 0.131.4の`SpringBoneCollision.TryResolveCapsuleCollision`と同じく、関節の先端ではなく根元をカプセル軸へ射影します。身体に付いたコライダーのワールド変換は毎フレーム1回だけ計算し、揺れ骨自身に付いたコライダーは姿勢変更後に計算します。

一人称の視点はvigworkの`AvatarRuntimeBinder.CreateEyeViewpoint`に合わせ、両眼中央の6cm前方をHMDの左右眼の中央へ合わせます。腰を追跡している場合も、頭はIK到達距離でクランプせず視点を優先します。`auto`のメッシュは頭の子孫ボーンにウェイトを持つ三角形を一人称だけで除き、顔と髪をPCカメラには表示します。近接クリップは1cmです。追跡診断は標準出力へ毎秒記録し、ゲーム内コンソールの履歴や文字描画を更新しません。
