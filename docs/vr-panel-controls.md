# VRパネルの調整

メニュー中か一時停止中にレイアウトの鍵を解除し、両方のコントローラーを追跡できる状態で操作します。

- パネルへ向けてグリップを押し続けると、そのパネルをつかみます。従来どおり手の移動・回転でも調整できます。
- つかんでいる側のジョイスティックを左右へ倒すと、パネルの横方向へ動きます。
- ジョイスティックを上へ倒すと奥へ、下へ倒すと手前へ動きます。
- グリップを離すと配置を保存します。HMDを外した場合や追跡が途切れた場合は、調整前の保存済み配置へ戻ります。
- 調整後は鍵を閉じると固定できます。

移動速度は`osu_vr_panel_joystick_speed`で指定でき、初期値は毎秒0.8mです。スティックの中央20%は移動しません。SteamVRがJoystick型として報告する軸を使い、タッチパッドの値は使用しません。

通常は右グリップが2D画面、左グリップがプレイ面を選びます。別のパネルへ直接向けた場合は、既存の選択判定が優先されます。トリガーのクリックと両手トリガーの拡大縮小は変更していません。
